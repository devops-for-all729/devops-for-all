# الديف أوبس من الصفر للإنتاج

موقع ثابت (static site) بالعربية عن الديف أوبس: التعريف، رحلة الكود من الـ commit للإنتاج، الأدوات الأساسية، وخطة بداية عملية.

## التشغيل محلياً
افتح `index.html` في المتصفح مباشرة، مفيش أي build step.

## النشر على Vercel
مشروع static خالص: Vercel بيكتشفه تلقائياً (Framework Preset: Other) من غير أي أمر build. الملفات تتقدم كما هي من جذر الريبو.

المحتوى:
- `index.html` الصفحة الرئيسية (عربي RTL)
- `styles.css` التنسيقات
- `devops-hero.svg` الرسم التوضيحي
